# PKU354: Addon Dependency Version Mismatch

## Error Message

```
[PKU354] An addon dependency resolves to a version outside the declared range
```

## What Went Wrong

An addon declares a dependency on another addon, and the version wired in your project does not satisfy the declared range.

## How to Fix

Wire a version of the dependency that satisfies the range, or update the addon.
