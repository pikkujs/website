# PKU361: Contributor Name Duplicated

## Error Message

```
[PKU361] A contributor is defined twice
```

## What Went Wrong

A contributor name appears in more than one `defineContributors` entry.

## How to Fix

Keep each contributor name in a single `defineContributors` entry.
