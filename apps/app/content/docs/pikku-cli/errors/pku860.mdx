# PKU860: Manifest Missing

## Error Message

```
[PKU860] Version manifest not found at /path/to/project/versions.pikku.json. Run 'pikku versions init' to create one.
```

## What Went Wrong

You ran `pikku versions check`, or a CI step that calls it, and the project has no `versions.pikku.json`.

The manifest records the input and output schema hashes of each function version. The check compares your code against it. With no manifest there is nothing to compare, so the command fails.

## How to Fix

Create the manifest, record your current functions, then commit the file:

```bash
npx pikku versions init
npx pikku versions update
git add versions.pikku.json
git commit -m "chore: record pikku contracts"
```

Run both Pikku commands. `init` only writes an empty manifest, and a check against an empty manifest always passes. Until `init` has run, `versions update` prints a warning and records nothing.

If the manifest should already exist, restore it from Git instead. A new one records your schemas as they are now, so a change made since the old one was lost goes unnoticed.

## Common Mistakes

- Adding `versions.pikku.json` to `.gitignore`. A fresh CI checkout then has no manifest.
- Setting a `rootDir` that does not contain the manifest. Pikku looks for it there.
