# PKU359: Studio Badge Function Not Found

## Error Message

```
[PKU359] A screen's nav badge names no function in this addon
```

## What Went Wrong

A screen sets `nav.badge` to a function name that is not defined in the addon.

## How to Fix

Point the badge at an existing function of the addon, or remove it.
