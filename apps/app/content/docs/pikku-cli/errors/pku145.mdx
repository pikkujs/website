# PKU145: Missing Model

## Error Message

```
[PKU145] AI agent 'supportAgent' is missing the 'model' property.
```

## What Went Wrong

Every AI agent must declare which model it runs on. The Pikku CLI validates this at build time so a missing model surfaces immediately, rather than as a runtime failure the first time someone talks to the agent. Your `pikkuAgent` definition has no `model` property (or it's set to an empty value).

## How to Fix

Add a provider-qualified `model` to the agent definition:

```typescript @snippet ea-agent-model
```

The model string must be in `<provider>/<model>` form — see [PKU146](/docs/pikku-cli/errors/pku146) if you have a model but it isn't provider-qualified.

## AI Agent Best Practices

- Always qualify the provider (`anthropic/…`, `openai/…`) so the runtime knows which API to call.
- Pick the model per agent, not globally — a triage agent and a reasoning agent rarely want the same one.
- Keep the model string a literal so the inspector can display it.

## Common Mistakes

Pulling the model from the environment at definition time (`model: process.env.AGENT_MODEL`) is a mistake too: the inspector can't see it. Use a literal:

```typescript @snippet ea-agent-model
```
