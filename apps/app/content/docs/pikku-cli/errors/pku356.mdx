# PKU356: Addon Dependency Invalid

## Error Message

```
[PKU356] An addon's declared dependencies are invalid
```

## What Went Wrong

An addon's declared dependencies could not be resolved or are malformed.

## How to Fix

Fix the dependency declaration in the addon's package.json as the message describes.
