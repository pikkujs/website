# PKU365: Studio Screen Agent Invalid

## Error Message

```
[PKU365] A screen names an invalid agent
```

## What Went Wrong

A screen's `agent` is not valid: it is neither the name of an agent the addon ships (lowercase letters, digits and hyphens, starting with a letter) nor `studio:<name>` for one Studio ships, or the named agent does not exist.

## How to Fix

Use a valid agent name that exists.
