# Pikku CLI

The Pikku CLI scans your codebase, analyzes your functions and wirings, and generates type-safe clients, entry points, schemas, and optimized bundles. It also scaffolds new code, manages function versioning, and deploys your project to cloud providers.

## Quick Start

```bash
npx pikku
```

This reads your `pikku.config.json`, scans the configured source directories, and generates everything into your `.pikku/` output directory — types, schemas, wiring metadata, RPC maps, and more.

## Commands

### `pikku` / `pikku all`

Generate all Pikku files (types, schemas, wirings, etc.). This is the default command.

```bash
npx pikku
npx pikku all
```

**Filtering flags** (apply to `all`):

| Flag                                          | Description                                                                                                                                         |
| --------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| `--filter`                                    | Named filter preset(s) from the `filters` map in `pikku.config.json` (comma-separated)                                                              |
| `--tags, -t` / `--exclude-tags`               | Include/exclude functions by tags (comma-separated)                                                                                                 |
| `--wires` / `--exclude-wires`                 | Include/exclude wirings by category (comma-separated): `http`, `channel`, `queue`, `scheduler`, `rpc`, `mcp`, `cli`, `workflow`, `trigger`, `agent` |
| `--directories, -d` / `--exclude-directories` | Include/exclude functions by directories (comma-separated)                                                                                          |
| `--http-methods` / `--exclude-http-methods`   | Include/exclude HTTP routes by methods (comma-separated)                                                                                            |
| `--http-routes` / `--exclude-http-routes`     | Include/exclude HTTP routes by route patterns (comma-separated)                                                                                     |
| `--names, -n` / `--exclude-names`             | Include/exclude functions by name patterns (supports wildcards)                                                                                     |
| `--target` / `--exclude-target`               | Include/exclude by deploy target (`serverless`, `server`)                                                                                           |

```bash
# Public HTTP API only
npx pikku --tags public --wires http

# Background workers only
npx pikku --wires queue,scheduler

# Specific routes
npx pikku --http-routes /api/admin
```

### `pikku bootstrap`

Generate only type files (setup phase). Useful when you need types before a full generation pass — for example, on first clone or in CI before the main build.

```bash
npx pikku bootstrap
```

### `pikku dev`

Start a local development server with all services wired. Watch mode and hot module reload are on by default, and the [Console](/docs/console) is available at `http://localhost:3000/console`.

```bash
npx pikku dev
npx pikku dev --port 8080        # Custom port (default: 3000)
npx pikku dev --no-watch         # Disable file watching
npx pikku dev --coverage         # Collect V8 precise coverage in-process
npx pikku dev --test             # Test mode: record service calls for scenario assertions
```

### `pikku serve`

Start a server using the bundled bun or node runner — no watch, no codegen. For running a built project.

```bash
npx pikku serve
npx pikku serve --port 8080
npx pikku serve --console        # Also serve the Console same-origin at /console
```

Both commands own the full server lifecycle — creating services, starting, and shutting down. Hook into it with [lifecycle hooks](/docs/core-features/server-lifecycle) rather than writing your own entrypoint.

### `pikku watch`

Watch for file changes and regenerate automatically. Your generated types stay in sync as you write code.

```bash
npx pikku watch
npx pikku watch --hmr   # Enable hot module reload for registered functions
```

### `pikku schemas`

Generate JSON schemas for function input/output types.

```bash
npx pikku schemas
```

### Client Generation

Generate type-safe clients for specific protocols:

```bash
npx pikku fetch          # HTTP fetch client
npx pikku websocket      # WebSocket client
npx pikku rpc            # RPC client wrappers
npx pikku react-query    # TanStack React Query hooks from the RPC map
npx pikku tanstack-start # TanStack Start server-function shim (makeApi)
npx pikku realtime       # Typed realtime client (WebSocket + SSE helper)
npx pikku queue-service  # Queue service wrapper
npx pikku openapi        # OpenAPI specification from HTTP routes
npx pikku nextjs         # Next.js backend and HTTP wrappers
```

These require the corresponding file paths to be set in `pikku.config.json` under `clientFiles` (e.g., `fetchFile`, `websocketFile`, `reactQueryFile`, `realtimeFile`, `startServerFnsFile`).

### `pikku new`

Scaffold new files from templates:

```bash
# Functions
npx pikku new function myFunc                    # Default: sessionless
npx pikku new function myFunc --type func        # Requires session
npx pikku new function myFunc --type void        # No return value

# Wirings
npx pikku new wiring myRoute                     # Default: http
npx pikku new wiring myRoute --type channel      # WebSocket channel
npx pikku new wiring myRoute --type scheduler    # Cron job
npx pikku new wiring myRoute --type queue        # Queue worker
npx pikku new wiring myRoute --type mcp          # MCP resource
npx pikku new wiring myRoute --type cli          # CLI command
npx pikku new wiring myRoute --type trigger      # Event trigger

# Middleware & Permissions
npx pikku new middleware myAuth                   # Default: simple
npx pikku new middleware myAuth --type factory    # Factory pattern
npx pikku new permission myGuard                  # Default: simple
npx pikku new permission myGuard --type factory   # Factory pattern

# Addons
npx pikku new addon my-integration
npx pikku new addon my-integration --secret       # Include secret schema
npx pikku new addon my-integration --variable     # Include variable definition
npx pikku new addon my-integration --oauth        # OAuth2 credential + API service
npx pikku new addon my-integration --credential apikey  # Per-user credential
npx pikku new addon my-integration --openapi ./spec.yaml  # Generate from OpenAPI spec
npx pikku new addon my-integration --mcp          # Expose functions as MCP tools
npx pikku new addon my-integration --camelCase    # Convert snake_case to camelCase in schemas
```

### `pikku enable`

Enable Pikku features by updating the `scaffold` section in `pikku.config.json`:

```bash
npx pikku enable rpc          # Enable public RPC endpoint
npx pikku enable console      # Enable console functions
npx pikku enable scenarios    # Enable scenario instrumentation functions
npx pikku enable agent        # Enable public agent endpoints
npx pikku enable workflow     # Enable workflow workers
npx pikku enable events       # Enable the realtime events channel + SSE stream
npx pikku enable remote-rpc   # Enable the remote internal RPC queue worker + HTTP endpoint

# Disable auth requirement
npx pikku enable rpc --no-auth
```

### `pikku versions`

Manage function contract versioning. Tracks input/output schema hashes to detect breaking changes.

```bash
npx pikku versions init      # Initialize version manifest (versions.pikku.json)
npx pikku versions init --force  # Overwrite existing manifest
npx pikku versions check     # Validate contracts against manifest
npx pikku versions update    # Update manifest with current hashes
```

### `pikku deploy`

Deploy your Pikku project to cloud infrastructure.

```bash
npx pikku deploy plan                    # Show what will be created/updated/deleted
npx pikku deploy plan --provider aws     # Use AWS provider (default: cloudflare)
npx pikku deploy apply                   # Execute the deployment
npx pikku deploy apply --from-plan       # Deploy from existing plan output
npx pikku deploy info                    # Show current deployment state
```

Both `plan` and `apply` accept `--runtime node|bun` for the standalone provider (bundle.js vs compiled executable) and `--result-file <path>` to write a structured JSON result.

**Providers:** `cloudflare` (default), `serverless`, `azure`, `standalone` — extendable via the `deploy.providers` map in `pikku.config.json`

The deploy pipeline builds your project, tree-shakes per deployment unit, and provisions infrastructure (workers, queues, cron triggers, secrets) through the provider API.

### `pikku info`

Inspect your Pikku project:

```bash
npx pikku info                           # List all functions (default)
npx pikku info functions                 # List all registered functions
npx pikku info functions --verbose       # Include file paths, services, etc.
npx pikku info tags                      # List all tags with associated functions
npx pikku info middleware                # List all middleware definitions
npx pikku info permissions               # List all permission definitions
npx pikku info --limit 100              # Show more rows (default: 50)
```

### `pikku db`

Local development database commands.

```bash
npx pikku db migrate    # Apply pending SQL migrations and regenerate db/schema.gen.ts
npx pikku db generate   # Generate SQL migrations from detected schema changes
npx pikku db seed       # Apply db/seed.sql to the dev database
npx pikku db reset      # Wipe and recreate the dev database (migrate + seed)
npx pikku db audit      # Report column classifications and flag columns with no anonymize strategy
```

### `pikku binary`

Compile a TypeScript entrypoint to a self-contained native binary via `bun build --compile`. Configure `binary.entrypoint`, `binary.output`, and `binary.targets` in `pikku.config.json`.

```bash
npx pikku binary
npx pikku binary --compile-target bun-linux-x64
```

### `pikku skills`

Install bundled agent skills (Claude Code today; Codex/Gemini coming soon).

```bash
npx pikku skills list                 # List bundled skills and which are installed
npx pikku skills install              # Copy bundled skills into the project
npx pikku skills install --core       # Only skills tagged installGroups: [core]
npx pikku skills install --fabric     # Only skills tagged installGroups: [fabric]
```

### `pikku meta`

Inspect project metadata in machine-readable form (for planners and tooling).

```bash
npx pikku meta context     # Bulk project context in one call
npx pikku meta clients     # Frontend-targeted metadata (exposed RPCs, workflows, channels)
npx pikku meta functions list
npx pikku meta wires list
```

### `pikku emails`

Typed email template generation.

```bash
npx pikku emails init       # Scaffold emailTemplatesDir with starter locales, theme, partials
npx pikku emails generate   # Generate typed email renderers and metadata
```

Requires `emailTemplatesDir` in `pikku.config.json`.

### `pikku scenario`

Run and inspect scenarios (`pikkuScenario`) against a configured environment. Environments live under `scenarios.environments` in `pikku.config.json`; the actor secret comes from the `SCENARIO_ACTOR_SECRET` environment variable.

```bash
npx pikku scenario list                    # List scenarios with names and descriptions
npx pikku scenario run staging             # Run all scenarios against the staging environment
npx pikku scenario run staging --flows onboarding,checkout
npx pikku scenario run staging --tags smoke
npx pikku scenario run local --coverage    # Per-scenario server coverage (target must run with --coverage)
```

### `pikku audit`

Audit dependencies for security advisories (always) and available updates (`--outdated`); writes `.pikku/audit.json`.

```bash
npx pikku audit
npx pikku audit --outdated
```

### `pikku workspace`

Workspace-level validation and maintenance.

```bash
npx pikku workspace validate   # Check the project structure for Pikku workspace compatibility
```

### `pikku login` / `pikku logout` / `pikku whoami`

Authenticate the CLI against a Pikku server (device-authorization flow). Used by commands that talk to a running server.

```bash
npx pikku login                          # Default: http://localhost:3000
npx pikku login --url https://api.example.com
npx pikku whoami                         # Show the current CLI session
npx pikku logout                         # Remove a stored CLI session
```

### `pikku fabric`

PikkuFabric commands (login, link, deploy, domains, secrets, logs, …). Run `npx pikku fabric` to see the subcommands.

## Global Options

These flags work with any command:

| Flag                                | Description                                                                                                          |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| `--config, -c`                      | Path to `pikku.config.json` file                                                                                     |
| `--log-level, -l`                   | Set log level (default: `info`)                                                                                      |
| `--output`                          | Output format: `text` (default) or `json` (emits NDJSON)                                                             |
| `--json, -j`                        | Alias for `--output json`                                                                                            |
| `--out-dir, -o`                     | Override output directory                                                                                            |
| `--user-session-type`               | Specify which UserSession type to use (when multiple exist)                                                          |
| `--singleton-services-factory-type` | Specify which singleton services factory to use                                                                      |
| `--wire-services-factory-type`      | Specify which wire services factory to use                                                                           |
| `--state-output`                    | Save inspector state to JSON file for reuse                                                                          |
| `--state-input`                     | Load inspector state from JSON (skips inspection)                                                                    |
| `--security`                        | Run the data-classification security lint (scans function return types for Private/Pii/Secret leaks). Off by default |
| `--fail-on-error`                   | Fail the build on error-severity diagnostics (default: only critical fail)                                           |
| `--fail-on-warn`                    | Fail the build on warn-severity diagnostics (implies `--fail-on-error`)                                              |
| `--tsc`                             | After codegen, run a real `tsc --noEmit` and fail on type errors (full diagnostics with code frames)                 |
| `--tsc-summary`                     | Like `--tsc` but prints a compact one-line-per-error summary — cheap for CI and AI agents                            |

## Common Workflows

### Development

```bash
# Run the whole platform locally, Console included
npx pikku dev

# Or just watch mode with hot reload, no server
npx pikku watch --hmr
```

### CI / Production Build

```bash
npx pikku
```

### Deploy

```bash
# Preview what will change
npx pikku deploy plan

# Ship it
npx pikku deploy apply
```

### Filter by Environment

```bash
# Public API only
npx pikku --tags public --wires http

# Admin service
npx pikku --tags admin --http-routes /admin

# Background workers
npx pikku --wires queue,scheduler
```

### Monorepo with Shared SDK

```json
{
  "clientFiles": {
    "fetchFile": "packages/sdk/pikku-fetch.gen.ts",
    "websocketFile": "packages/sdk/pikku-websocket.gen.ts"
  },
  "packageMappings": {
    "packages/sdk": "@my-app/sdk"
  }
}
```
