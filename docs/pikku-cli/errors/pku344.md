# PKU344: Addon Expose Not Static

## Error Message

```
[PKU344] wireAddon's expose must be true, false or an array of string literals, got: SELECTED
```

## What Went Wrong

`wireAddon`'s `expose` was given something the build can't read without running your code: a variable, a spread, or a function call.

The build needs the exact list. The deploy analyzer uses it to decide which addon functions go into the unit that serves `/rpc`, and the ungated-function warning ([PKU574](./pku574.md)) uses it to check what you've opened. If it guessed, the deployed units could disagree with what the runtime allows.

## How to Fix

Write the list inline:

```typescript title="wirings/addons.wirings.ts"
// ❌ Wrong: the build can't see what SELECTED holds
const SELECTED = ['getOrder', 'listOrders']
wireAddon({ name: 'shop', package: '@acme/addon-shop', expose: SELECTED })
```

```typescript title="wirings/addons.wirings.ts"
// ✅ Correct
wireAddon({
  name: 'shop',
  package: '@acme/addon-shop',
  expose: ['getOrder', 'listOrders'],
})
```

`true` and `false` are also fine.
