# PKU348: Addon Needs Not Mapped

## Error Message

```
[PKU348] [package] needs [needed], but wireAddon('[name]') does not map it. Wire [needed] and add uses: { '[needed]': '<name>' } to this wireAddon.
```

## What Went Wrong

The addon package declares other addons it needs (`pikku.uses` in its `package.json`). Your `wireAddon` for it has no `uses` entry for one of them, so the host cannot tell which wired addon should satisfy the dependency.

Remote addons (`wireRemoteAddon`) are not checked: they are types only and their dependencies live on the host that runs them.

## How to Fix

1. Wire the needed addon in your app if you have not already.
2. Add a `uses` entry on the dependent `wireAddon`, mapping the needed package to the name you wired it under.
3. Run `pikku all` again.
