# PKU349: Addon Content Grant Invalid

## Error Message

```
[PKU349] Addon '[name]' grants '[prefix]' as '[mode]', but a content grant must be 'read' or 'write'.
[PKU349] Addon '[name]' grants content under '[prefix]', but '[first segment]' is not the content bucket of any wired addon. Buckets: [names]
```

## What Went Wrong

`contentGrants` on `wireAddon` lets an addon read or write content that belongs to another addon's bucket. Each entry maps a path prefix to a mode. Two things are checked:

- the mode must be exactly `read` or `write`;
- the first path segment of the prefix must be the content bucket of a wired addon. A bucket is the addon's `contentBucket` if it set one, otherwise its wired name.

## How to Fix

1. Use `read` or `write` as the mode.
2. Start the prefix with the bucket name of the addon that owns the content. The message lists the buckets that exist.
3. If the owner is not wired yet, wire it first.
4. Run `pikku all` again.
