# PKU568: Handler Not Resolved

## Error Message

```
[PKU568] Could not resolve handler '[functionName]' referenced by wiring '[name]' to a function definition.
```

## What Went Wrong

A wiring references a function handler, but the inspector couldn't trace that reference back to an actual definition. The `func` value is a name Pikku recognises as *intended* to be a function, but it can't find where that function is defined.

This is usually an import problem: the function isn't exported, the import path is wrong, or the name was renamed on one side but not the other. Because Pikku resolves handlers statically across your source files, a broken import chain means it never reaches the `pikkuFunc` definition — so it can't wire it, validate it, or generate its types.

## How to Fix

Make sure the referenced function is exported and imported with the correct name and path:

```typescript title="users.functions.ts"
// ❌ Wrong — not exported, so it can't be resolved from the wiring file
const getUsers = pikkuFunc(async () => {
  return { users: [] }
})
```

```typescript title="users.functions.ts"
// ✅ Correct — exported
import { pikkuFunc } from '#pikku'

export const getUsers = pikkuFunc(async () => {
  return { users: [] }
})
```

```typescript title="users.wiring.ts"
// ✅ Correct — imported with the matching name and path
import { wireHTTP } from '@pikku/core/http'
import { getUsers } from './users.functions'

wireHTTP({
  method: 'get',
  route: '/api/users',
  func: getUsers,
})
```

If you renamed the function, update every import that references it — a renamed export with a stale import is the most common trigger.

## Handler Resolution Best Practices

- Export every function you reference in a wiring; unexported functions can't be resolved.
- Import handlers by their exact exported name and correct relative/alias path.
- When you rename a function, rename its imports too — don't leave a dangling reference.

## Common Mistakes

```typescript title="wrong.ts"
// ❌ Import name doesn't match the export (typo / rename drift)
import { getUser } from './users.functions' // exported as getUsers

wireHTTP({ method: 'get', route: '/api/users', func: getUser })
```

```typescript title="correct.ts"
// ✅ Names match the export
import { getUsers } from './users.functions'

wireHTTP({ method: 'get', route: '/api/users', func: getUsers })
```
