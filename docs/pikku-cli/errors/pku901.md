# PKU901: Workflow Multi-Queue Not Supported

## Error Message

```
[PKU901] Workflow 'processOrder' has queued steps spread across more than one queue
('orders-queue', 'emails-queue'). A workflow's queued steps must all target a single queue.
```

## What Went Wrong

Pikku found a workflow whose queued steps — functions marked `workflowQueued: true` — are wired to more than one queue backend. A single workflow run is orchestrated against one queue: its steps are dispatched to, and picked up from, the same queue so the orchestrator can track and resume them durably. When those steps fan out across different queues, there's no single place to coordinate the run, so Pikku stops rather than generate wiring that can't be executed reliably.

This is a current limitation, not a bug in your code. The workflow itself is valid — it just can't be split across queue backends yet. You'll fix it by consolidating the queued steps onto one queue, or by splitting the work into separate workflows.

## How to Fix

Point every queued step in the workflow at the same queue.

```typescript title="process-order.workflow.ts"
// ❌ Wrong — queued steps target two different queues
export const chargeCard = pikkuFunc({
  workflowQueued: true,
  queue: 'orders-queue',
  func: async ({ payments }, input) => payments.charge(input),
})

export const sendReceipt = pikkuFunc({
  workflowQueued: true,
  queue: 'emails-queue', // different queue → PKU901
  func: async ({ email }, input) => email.sendReceipt(input),
})

export const processOrder = pikkuWorkflowFunc(async (workflow, input) => {
  await workflow.do('charge', 'chargeCard', input)
  await workflow.do('receipt', 'sendReceipt', input)
})
```

```typescript title="process-order.workflow.ts"
// ✅ Correct — all queued steps share one queue
export const chargeCard = pikkuFunc({
  workflowQueued: true,
  queue: 'orders-queue',
  func: async ({ payments }, input) => payments.charge(input),
})

export const sendReceipt = pikkuFunc({
  workflowQueued: true,
  queue: 'orders-queue', // same queue as every other queued step
  func: async ({ email }, input) => email.sendReceipt(input),
})

export const processOrder = pikkuWorkflowFunc(async (workflow, input) => {
  await workflow.do('charge', 'chargeCard', input)
  await workflow.do('receipt', 'sendReceipt', input)
})
```

If two groups of steps genuinely need different queues — for example a high-priority payments queue and a bulk email queue — split them into two workflows, one per queue, and have the first call the second.

## Workflow Best Practices

- Decide a workflow's queue up front and route every `workflowQueued: true` step in it to that one queue.
- Split by queue, not by convenience: if steps need different queue backends or priorities, model them as separate workflows rather than mixing queues in one.
- Leave latency-sensitive or trivial steps un-queued — only mark a step `workflowQueued: true` when it needs the durability and isolation of a queue.

## Common Mistakes

```typescript title="wrong.ts"
// ❌ A shared step function pulled into a workflow that uses a different queue
export const notify = pikkuFunc({
  workflowQueued: true,
  queue: 'notifications-queue',
  func: async ({ email }, input) => email.send(input),
})
// Reused inside a workflow whose other steps target 'orders-queue' → PKU901
```

```typescript title="correct.ts"
// ✅ Give the workflow its own step wired to the workflow's queue
export const notifyOrder = pikkuFunc({
  workflowQueued: true,
  queue: 'orders-queue',
  func: async ({ email }, input) => email.send(input),
})
```
