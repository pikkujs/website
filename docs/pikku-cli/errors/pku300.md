# PKU300: Invalid Handler

## Error Message

```
[PKU300] Handler for '[name]' is not a valid function reference. Expected a function wrapped with pikkuFunc().
```

## What Went Wrong

A wiring's `func` (or handler) property points at something that isn't a valid Pikku function. This usually means you passed a plain inline function, an arbitrary value, or an expression the inspector can't recognise as a `pikkuFunc`/`pikkuSessionlessFunc`.

Pikku can only wire, validate, and generate types for handlers it can identify. A raw `async () => {}` or a non-function value carries no metadata — no input/output schema, no permissions, no session requirements — so Pikku refuses it rather than silently wiring something it can't reason about.

## How to Fix

Pass an exported function that's been wrapped with `pikkuFunc` or `pikkuSessionlessFunc`:

```typescript title="greeting.functions.ts"
import { wireHTTP } from '@pikku/core/http'
import { pikkuFunc } from '#pikku'

// ❌ Wrong — inline plain function, not a pikkuFunc
wireHTTP({
  method: 'post',
  route: '/api/greeting',
  func: async (input: { name: string }) => {
    return { message: `Hello ${input.name}` }
  },
})
```

```typescript title="greeting.functions.ts"
// ✅ Correct — wrapped and referenced by name
export const greet = pikkuFunc<{ name: string }, { message: string }>(
  async (services, { name }) => {
    return { message: `Hello ${name}` }
  }
)

wireHTTP({
  method: 'post',
  route: '/api/greeting',
  func: greet,
})
```

Sessionless endpoints (no authenticated user) use `pikkuSessionlessFunc`:

```typescript
import { pikkuSessionlessFunc } from '#pikku'

export const healthCheck = pikkuSessionlessFunc(async () => {
  return { status: 'ok' }
})
```

## Handler Best Practices

- Define the function with `pikkuFunc`/`pikkuSessionlessFunc` and reference it by name in the wiring — don't inline it.
- Export the function so the inspector can resolve it across files.
- Keep one handler per wiring; if two routes share logic, extract a shared `pikkuFunc` and reference it from both.

## Common Mistakes

```typescript title="wrong.ts"
// ❌ A value that isn't a function at all
wireHTTP({
  method: 'get',
  route: '/api/config',
  func: someConfigObject,
})
```

```typescript title="correct.ts"
// ✅ A pikkuFunc reference
export const getConfig = pikkuSessionlessFunc(async ({ variables }) => {
  return { region: variables.get('REGION') }
})

wireHTTP({
  method: 'get',
  route: '/api/config',
  func: getConfig,
})
```
