# PKU921: Addon Contract Handlers Not Allowed

## Error Message

```
[PKU921] Addon contract 'defineHTTPRoutes' must not declare middleware or permissions — these are applied by the consuming app, not the addon.
```

## What Went Wrong

Your addon's contract declaration (`defineHTTPRoutes`, `defineChannelRoutes`, or `defineCLICommands`) includes a `middleware` or `permissions` property. Contracts describe *what* an addon offers — routes, channels, commands and their functions — but cross-cutting behaviour like auth middleware and permission checks is the **consuming app's** policy. An addon baking in its own middleware would run code the consumer can't see or replace, with the consumer's session and services.

## How to Fix

Strip middleware/permissions from the contract; consumers attach their own when wiring:

```typescript title="addon: src/todos.contract.ts"
// ❌ Wrong — contract carries handlers
export const todosRoutes = defineHTTPRoutes({
  middleware: [rateLimit()],
  routes: [
    { method: 'get', route: '/todos', func: listTodos, permissions: { isAdmin } },
  ],
})
```

```typescript title="addon: src/todos.contract.ts"
// ✅ Correct — pure contract
export const todosRoutes = defineHTTPRoutes({
  routes: [{ method: 'get', route: '/todos', func: listTodos }],
})
```

```typescript title="consuming app: src/addons.wiring.ts"
// ✅ The app applies its own policy at wiring time
wireHTTPRoutes({
  middleware: [rateLimit()],
  permissions: { isAdmin },
  ...refHTTP('todos', 'todosRoutes'),
})
```

If your addon has real authorization *requirements*, express them in the function bodies (e.g. checking the session your consumer's auth provides) or document required permissions in the README — don't hardcode handlers into the contract.

## Addon Authoring Best Practices

- Contracts are data, not behaviour: routes, names, functions — no handler properties.
- Functions inside addons should assume the consumer's middleware ran; validate the session, don't create it.
- Ship a suggested wiring snippet (with recommended middleware) in your docs instead of embedding it.
