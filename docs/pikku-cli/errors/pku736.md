# PKU736: Middleware Empty Array

## Error Message

```
[PKU736] addHTTPMiddleware was called with an empty middleware array.
```

## What Went Wrong

You called `addHTTPMiddleware(pattern, [])` with an empty array, so the wiring registers no middleware at all. This is a no-op — the pattern matches routes, but there's nothing to run against them. Pikku flags it because an empty array almost always signals a mistake: middleware that was removed but left the call behind, an array that was meant to be filled in, or an import that didn't resolve.

If the emptiness is intentional (for example, a placeholder you'll fill later), the call still does nothing useful today, so it's better to remove it until you have middleware to attach.

## How to Fix

Include at least one `pikkuMiddleware` in the array, or remove the call entirely:

```typescript title="wrong.ts"
// ❌ Wrong — empty array, registers nothing
export const httpGlobal = () => addHTTPMiddleware('*', [])
```

```typescript title="correct.ts"
// ✅ Correct — at least one middleware to run
export const httpGlobal = () => addHTTPMiddleware('*', [logRequest, requireAuth])
```

If you no longer have middleware for this pattern, delete the wiring rather than leaving an empty one:

```typescript title="correct.ts"
// ✅ Correct — no wiring at all is clearer than an empty one
// (removed the addHTTPMiddleware('*', []) call)
```

## Middleware Best Practices

- Only wire a pattern once you have concrete middleware to attach — an empty group adds indirection without behaviour.
- Verify your middleware imports resolve; a bad import can collapse the array to empty without an obvious error.
- Keep each `addHTTPMiddleware` call focused on one pattern so it's easy to see what runs where.

## Common Mistakes

```typescript title="wrong.ts"
// ❌ Wrong — middleware commented out, empty array left behind
export const apiMiddleware = () =>
  addHTTPMiddleware('/api/*', [
    // authMiddleware,
  ])
```

```typescript title="correct.ts"
// ✅ Correct — restore the middleware, or drop the call
export const apiMiddleware = () => addHTTPMiddleware('/api/*', [authMiddleware])
```
