# PKU346: Addon Sets ui But Declares No Screens

## Error Message

```
[PKU346] wireAddon('[name]') sets ui: true, but [package] declares no screens. Add a defineScreens call to the package, or drop ui.
```

## What Went Wrong

`ui: true` on `wireAddon` asks the host to mount the screens the addon ships. The package you named has a screens manifest with no screens, or none at all, so there is nothing to mount.

## How to Fix

If the package only ships functions, drop `ui`:

```typescript
import { wireAddon } from '#pikku/addon'

wireAddon({ name: 'invoices', package: '@acme/addon-invoices' })
```

If it should ship screens, declare them in the package with `defineScreens` and run `pikku all` there so the screens manifest is published:

```typescript
wireAddon({ name: 'invoices', package: '@acme/addon-invoices', ui: true })
```

Scaffold a package that does this with `pikku new addon <name> --ui`.
