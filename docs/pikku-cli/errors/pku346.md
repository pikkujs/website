# PKU346: Extension Declares No Screens

## Error Message

```
[PKU346] '[package]' is wired with wireExtension but declares no screens. It is an addon. Use wireAddon.
```

## What Went Wrong

`wireExtension` installs a package that ships screens for Pikku Studio. The package you named has a manifest with no screens, or none at all, so there is nothing for Studio to mount under `/extensions/<name>`.

## How to Fix

If the package only ships functions, it is an addon. Wire it as one:

```typescript
import { wireAddon } from '#pikku/addon'

wireAddon({ name: 'invoices', package: '@acme/addon-invoices' })
```

If it should ship screens, declare them in the package with `defineExtension` and run `pikku all` there so the extension meta is published.
