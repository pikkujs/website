# PKU490: Schema and Wiring Colocated

## Error Message

```
[PKU490] File 'src/todos.ts' contains both Zod schemas (CreateTodoInput, TodoOutput) and wiring calls (wireHTTPRoutes, addPermission, etc.). These must be in separate files because the CLI imports schema files at runtime, which triggers wiring side-effects that crash without server context. Move the route/wiring definitions to a dedicated wiring file.
```

## What Went Wrong

One of your files defines runtime schemas (Zod/Valibot/etc.) **and** makes wiring calls (`wireHTTPRoutes`, `addPermission`, `addHTTPMiddleware`, …).

To extract schemas, the Pikku CLI actually imports the file at build time — which executes all of its top-level code. Wiring calls are top-level side-effects that expect a running Pikku state to register into; inside the CLI process that state doesn't exist, so the import crashes (or worse, half-registers things). Pikku detects the overlap statically and fails the build with a clear message instead.

## How to Fix

Split the file: schemas in one file, wiring in another.

```typescript title="todos.ts"
// ❌ Wrong — schemas and wiring in the same file
export const CreateTodoInput = z.object({ text: z.string() })

wireHTTPRoutes({
  routes: [{ method: 'post', route: '/todos', func: createTodo }],
})
```

```typescript title="todos.schemas.ts"
// ✅ Correct — schemas live alone
import { z } from 'zod'
export const CreateTodoInput = z.object({ text: z.string() })
```

```typescript title="todos.wiring.ts"
// ✅ Correct — wiring lives in a wiring file
wireHTTPRoutes({
  routes: [{ method: 'post', route: '/todos', func: createTodo }],
})
```

Function definitions can live with either — the rule is only about schema definitions sharing a file with wiring side-effects.

## Project Layout Best Practices

- Adopt the scaffold convention: `*.schemas.ts` (or types), `*.functions.ts`, `*.wiring.ts`.
- Keep wiring files free of any exports other than wiring — they exist for side-effects.
- If a build starts failing after a refactor, check whether a schema was moved into a wiring file during the merge.
