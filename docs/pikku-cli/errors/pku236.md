# PKU236: Missing Function Property

## Error Message

```
[PKU236] No valid 'func' property for [route|tool|resource|prompt|task|processor] '[name]'.
```

## What Went Wrong

Your wiring configuration is missing the required `func` property, or the function provided is not a valid `pikkuFunc`.

## How to Fix

Make sure you provide a valid `pikkuFunc` for your endpoint:

### HTTP Route Example

```typescript
import { wireHTTP } from '#pikku/http'
import { pikkuFunc } from '#pikku/function'

const myHandler = pikkuFunc<{ name: string }, { message: string }>({
  func: async (services, data) => ({ message: `Hello ${data.name}` }),
})

wireHTTP({
  method: 'post',
  route: '/api/greeting',
  func: myHandler, // ✅ Add this
})
```

### MCP Resource Example

```typescript
import { wireMCPResource, pikkuMCPResourceFunc } from '#pikku/mcp'

const readSettings = pikkuMCPResourceFunc<unknown>(async () => [
  { uri: 'file:///config/settings', text: '{}' },
])

wireMCPResource({
  uri: 'file:///config/settings',
  title: 'Application Settings',
  description: 'Current application configuration',
  func: readSettings, // ✅ Add this
})
```

### Scheduled Task Example

```typescript
import { wireScheduler } from '#pikku/scheduler'
import { pikkuVoidFunc } from '#pikku/function'

const hourlyTask = pikkuVoidFunc({
  func: async () => {
    // Run every hour
  },
})

wireScheduler({
  name: 'hourlyTask',
  schedule: '0 * * * *',
  func: hourlyTask, // ✅ Add this
})
```

## Common Mistakes

- Omitting the `func` property entirely
- Providing a regular function instead of a `pikkuFunc`
- Providing `null` or `undefined` as the function value
- Misspelling `func` as `function` or `handler`
