# PKU118: Non-Literal Wire Name

## Error Message

```
[PKU118] Queue worker has a non-literal 'name': `QUEUE_NAME`. Wiring identity fields must be inline string literals — the inspector reads them statically from source, so a const or variable reference is keyed by its identifier text and the wiring is silently skipped at runtime. Inline the literal instead, e.g. name: 'my-wiring-name'.
```

## What Went Wrong

You passed a variable, constant, or expression as the identity field of a wiring (the `name` of a queue worker, channel, scheduler, and so on) instead of an inline string literal.

The Pikku CLI doesn't run your code — it reads it statically with the TypeScript compiler. When the inspector sees `name: QUEUE_NAME`, it can't evaluate the variable, so the wiring would be keyed by the identifier text (`QUEUE_NAME`) rather than the actual value (`'send-emails'`). At runtime the two never match up and the wiring is silently skipped. Pikku fails the build instead of letting that happen.

## How to Fix

Inline the string literal directly in the wiring call:

```typescript title="email.wiring.ts"
// ❌ Wrong — the inspector can't resolve the constant
const QUEUE_NAME = 'send-emails'

wireQueueWorker({
  name: QUEUE_NAME,
  func: sendEmails,
})
```

```typescript title="email.wiring.ts"
// ✅ Correct — inline literal, readable statically
wireQueueWorker({
  name: 'send-emails',
  func: sendEmails,
})
```

If you need the name elsewhere (e.g. when enqueueing jobs), Pikku's generated types are the source of truth — the queue name becomes part of the typed client, so you don't need a shared constant to keep them in sync.

## Wiring Best Practices

- Treat wiring files as declarative configuration: literals only, no computed values in identity fields.
- Template literals without substitutions (`` name: `send-emails` ``) are fine; anything with `${...}` is not.
- Let codegen propagate names to consumers instead of exporting shared constants.

## Common Mistakes

```typescript title="wrong.ts"
// ❌ Wrong — computed name, causes PKU118
wireChannel({ name: `chat-${env}`, ... })
```

```typescript title="correct.ts"
// ✅ Correct — one wiring per literal name
wireChannel({ name: 'chat', ... })
```
