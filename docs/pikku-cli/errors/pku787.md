# PKU787: Middleware Pattern Invalid

## Error Message

```
[PKU787] Route pattern for addHTTPMiddleware must be a non-empty string literal.
```

## What Went Wrong

The first argument to `addHTTPMiddleware(pattern, [...])` is the route pattern — the string that decides which HTTP routes the middleware runs against (for example `'*'` for every route, or `'/api/*'` for a subtree). Pikku received a pattern it couldn't read: an empty string, or a value that isn't a plain string literal (a variable, a computed expression, a template literal with interpolation).

Pattern matching is resolved at build time, so the inspector has to see the literal pattern in your source. When the value only exists at runtime, there's nothing to match routes against, and the middleware wiring is dropped.

## How to Fix

Pass a literal pattern string:

```typescript title="wrong.ts"
// ❌ Wrong — empty pattern
export const httpGlobal = () => addHTTPMiddleware('', [logRequest])

// ❌ Wrong — pattern computed at runtime
const base = getBasePath()
export const apiMiddleware = () => addHTTPMiddleware(base, [authMiddleware])
```

```typescript title="correct.ts"
// ✅ Correct — '*' matches every route
export const httpGlobal = () => addHTTPMiddleware('*', [logRequest])

// ✅ Correct — '/api/*' matches the /api subtree
export const apiMiddleware = () => addHTTPMiddleware('/api/*', [authMiddleware])
```

## Middleware Best Practices

- Use `'*'` for middleware that must run on every request, and a prefixed pattern like `'/api/*'` to scope it to a subtree.
- Keep the pattern a plain string literal so Pikku can resolve route matching statically.
- Wrap `addHTTPMiddleware` in a factory (`export const x = () => ...`) so the wiring stays tree-shakeable.

## Common Mistakes

```typescript title="wrong.ts"
// ❌ Wrong — template literal with interpolation isn't a plain literal
const version = 'v2'
export const apiMiddleware = () =>
  addHTTPMiddleware(`/${version}/api/*`, [authMiddleware])
```

```typescript title="correct.ts"
// ✅ Correct — write the pattern out in full
export const apiMiddleware = () =>
  addHTTPMiddleware('/v2/api/*', [authMiddleware])
```
