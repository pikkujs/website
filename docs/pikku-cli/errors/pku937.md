# PKU937: Permission Empty Array

## Error Message

```
[PKU937] Permission wiring was given an empty array. Provide at least one pikkuPermission or remove the wiring.
```

## What Went Wrong

You registered a permission wiring but passed an empty array (`[]`) as the list of permission checks. An empty permission group is a no-op — it attaches nothing, protects nothing, and almost always signals a mistake: either you forgot to add the `pikkuPermission` you intended, or the wiring is left over and should be removed.

Pikku flags this at build time so an empty array doesn't quietly leave a route or function unprotected while looking like it has authorization applied.

## How to Fix

Include at least one `pikkuPermission` in the array:

```typescript title="permissions.ts"
import { pikkuPermission } from '#pikku'
import { addHTTPPermission } from '@pikku/core/http'

export const authenticated = pikkuPermission(async (ctx) => {
  if (!ctx.session?.userId) {
    throw new Error('Authentication required')
  }
})

// ✅ Correct: at least one permission
export const apiPermissions = () =>
  addHTTPPermission('/api/*', [authenticated])
```

Or, if you don't need permissions here, remove the wiring entirely:

```typescript title="routes.ts"
// ✅ Correct: no empty permissions array left behind
wireHTTP({
  method: 'get',
  route: '/api/health',
  func: healthCheck,
})
```

## Permission Best Practices

- Never leave an empty `permissions: []` or `addHTTPPermission(pattern, [])` in place — remove the wiring instead of leaving a no-op that looks protective.
- If a route is intentionally public, express that by omitting permissions (and setting `auth: false` where appropriate), not with an empty array.
- Compose reusable `pikkuPermission` checks so a wiring always has a concrete check to apply.

## Common Mistakes

```typescript title="wrong.ts"
// ❌ Wrong — empty array causes PKU937
export const apiPermissions = () =>
  addHTTPPermission('/api/*', [])

// ❌ Wrong — empty permissions on a route
wireHTTP({
  method: 'post',
  route: '/api/users',
  func: createUser,
  permissions: [],
})
```

```typescript title="correct.ts"
// ✅ Correct — a real permission is applied
wireHTTP({
  method: 'post',
  route: '/api/users',
  func: createUser,
  permissions: [authenticated],
})
```
