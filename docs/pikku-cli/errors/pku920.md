# PKU920: Addon Wiring Not Allowed

## Error Message

```
[PKU920] Addons must not call 'wireHTTPRoutes'. Declare contracts with define* and export functions; the consuming app wires them via refHTTP / refChannel / refCLI.
```

## What Went Wrong

You're building an **addon** (the CLI is running with addon inspection, e.g. via `pikku new addon` scaffolding or an addon package build) and one of its files calls a wiring helper — `wireHTTPRoutes`, `wireChannel`, `wireQueueWorker`, `wireScheduler`, `wireCLI`, `wireGateway`, `wireMCPResource`, `wireTrigger`, or similar.

Addons are libraries of functions plus *contracts*; the decision of what actually gets exposed — on which routes, with which middleware, in which app — belongs to the **consuming application**. If an addon wired routes itself, installing it would silently mount endpoints the consumer never asked for. So wiring calls are banned in addon packages; service declarations remain allowed.

## How to Fix

Replace wiring calls with contract declarations, and let consumers wire them:

```typescript title="addon: src/todos.wiring.ts"
// ❌ Wrong — addon wires routes directly
wireHTTPRoutes({
  routes: [{ method: 'get', route: '/todos', func: listTodos }],
})
```

```typescript title="addon: src/todos.contract.ts"
// ✅ Correct — addon declares the contract
export const todosRoutes = defineHTTPRoutes({
  routes: [{ method: 'get', route: '/todos', func: listTodos }],
})
```

```typescript title="consuming app: src/addons.wiring.ts"
// ✅ The APP decides to mount it (and where)
wireHTTPRoutes(refHTTP('todos:todosRoutes', { basePath: '/api' }))
```

`refHTTP` takes a single `'<namespace>:<contractName>'` key — the same `namespace:name` form as `ref('todos:listTodos')` — plus an optional `{ basePath }` to mount the contract somewhere other than where the addon put it. `refChannel` and `refCLI` take the key only.

The same pattern applies per transport: `defineChannelRoutes` + `refChannel`, `defineCLICommands` + `refCLI`.

## Addon Authoring Best Practices

- An addon exports functions, contracts (`define*`), and service declarations — nothing with side-effects on transports.
- Leave middleware and permissions out of contracts too ([PKU921](./pku921.md)); consumers attach their own.
- Document the intended wiring in the addon README so consumers can copy a working `ref*` snippet.
