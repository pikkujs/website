# PKU427: Config Type Undefined

## Error Message

```
[PKU427] The Config type resolved to undefined. Make sure your Config interface has a concrete definition extending CoreConfig.
```

## What Went Wrong

Pikku found a `Config` reference in your project, but it resolved to `undefined` — the type exists in name only. This is different from [PKU426](./pku426.md), where no `Config` type is found at all. Here the symbol is present but the inspector can't resolve it to a concrete interface.

This typically happens when `Config` is declared but never given a body, is aliased to something the type checker can't resolve, or is re-exported from a barrel file where the original definition was removed or renamed. Without a resolvable shape, Pikku can't understand your application's configuration.

## How to Fix

Define a concrete `Config` interface that extends `CoreConfig` and make sure it's exported and resolvable:

```typescript title="config.ts"
// ❌ Wrong — declared but empty/unresolved
export type Config = undefined

// ❌ Wrong — re-exported from a module that no longer defines it
export type { Config } from './old-config'
```

```typescript title="config.ts"
// ✅ Correct — a concrete interface with a resolvable definition
import { CoreConfig } from '@pikku/core'

export interface Config extends CoreConfig {
  apiKey: string
  databaseUrl: string
  environment: 'development' | 'production'
}
```

If you don't need any custom fields, extend `CoreConfig` with an empty interface — this still resolves to a concrete type:

```typescript title="config.ts"
import { CoreConfig } from '@pikku/core'

export interface Config extends CoreConfig {}
```

## Config Type Best Practices

- Prefer an `interface Config extends CoreConfig` over a `type` alias — interfaces resolve more reliably.
- Keep the `Config` definition in a file inside one of the `srcDirectories` from `pikku.config.json`.
- When re-exporting `Config` through a barrel, confirm the original definition still exists and hasn't been renamed.

## Common Mistakes

```typescript title="wrong.ts"
// ❌ Alias points at a type that doesn't exist / resolves to undefined
import type { AppSettings } from './settings'
export type Config = AppSettings
```

```typescript title="correct.ts"
// ✅ Concrete, exported interface extending CoreConfig
import { CoreConfig } from '@pikku/core'

export interface Config extends CoreConfig {
  apiKey: string
}
```
