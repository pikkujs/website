# PKU975: Permission Pattern Invalid

## Error Message

```
[PKU975] Route pattern for pattern-based permission wiring must be a valid pattern string (e.g. '*' or '/api/*').
```

## What Went Wrong

You're wiring permissions by route pattern, but the pattern you passed isn't a valid pattern string. Pattern-based permission wiring applies a set of `pikkuPermission` checks to every route whose path matches the pattern — so the CLI needs a concrete, literal pattern at build time to know which routes are covered.

This typically happens when the pattern is an empty string, a non-string value, or a variable or expression the CLI can't resolve statically. The match is computed during code generation, so a value that only exists at runtime can't be used here.

## How to Fix

Pass a literal pattern string — `'*'` for all routes, or a path glob like `'/api/*'`:

```typescript title="permissions.ts"
import { pikkuPermission } from '#pikku'
import { addHTTPPermission } from '@pikku/core/http'

export const authenticated = pikkuPermission(async (ctx) => {
  if (!ctx.session?.userId) {
    throw new Error('Authentication required')
  }
})

// ✅ Correct: apply to every route
export const globalPermissions = () =>
  addHTTPPermission('*', [authenticated])

// ✅ Correct: apply to a route prefix
export const apiPermissions = () =>
  addHTTPPermission('/api/*', [authenticated])
```

## Permission Best Practices

- Use a literal pattern string — never a variable or computed expression the CLI can't resolve at build time.
- Scope patterns as narrowly as the routes require (`'/api/*'` over `'*'`) so permissions only run where they're meant to.
- Keep pattern-based wiring in a factory function (`export const x = () => addHTTPPermission(...)`) for tree-shaking, matching the pattern used across Pikku wiring.

## Common Mistakes

```typescript title="wrong.ts"
// ❌ Wrong — empty pattern causes PKU975
export const apiPermissions = () =>
  addHTTPPermission('', [authenticated])

// ❌ Wrong — non-literal pattern can't be resolved at build time
const pattern = getPattern()
export const apiPermissions = () =>
  addHTTPPermission(pattern, [authenticated])
```

```typescript title="correct.ts"
// ✅ Correct — a valid literal pattern
export const apiPermissions = () =>
  addHTTPPermission('/api/*', [authenticated])
```
