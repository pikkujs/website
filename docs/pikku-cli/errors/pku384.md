# PKU384: Missing Queue Name

## Error Message

```
[PKU384] No 'name' provided for queue processor function '[functionName]'.
```

## What Went Wrong

You're wiring a queue worker without specifying which queue it should process. Every queue worker needs a `name` to know which queue to listen to — it's the same string whoever enqueues the job uses.

## How to Fix

Add a `name` property to your queue worker:

```typescript
import { wireQueueWorker } from '#pikku/queue'
import { sendEmail } from './functions/email.function.js'

wireQueueWorker({
  name: 'email-queue', // ✅ Add this
  func: sendEmail,
})
```

## Queue Name Guidelines

- Use descriptive, kebab-case names (e.g., `email-queue`, `image-processing`)
- Be consistent across your application
- Consider using a naming convention like `[domain]-[action]-queue`

## Common Patterns

```typescript
// Single queue for a specific task
wireQueueWorker({
  name: 'email-notifications',
  func: emailProcessor,
})

// Multiple workers for the same queue (parallel processing)
wireQueueWorker({
  name: 'data-processing',
  func: dataProcessor1,
})

wireQueueWorker({
  name: 'data-processing', // Same queue name
  func: dataProcessor2,
})

// Priority queues
wireQueueWorker({
  name: 'high-priority-tasks',
  func: highPriorityProcessor,
})

wireQueueWorker({
  name: 'low-priority-tasks',
  func: lowPriorityProcessor,
})
```

## Common Mistakes

- Omitting the `name` property
- Using an empty string as the queue name
- Misspelling the property as `queue` or `queueName` instead of `name`
