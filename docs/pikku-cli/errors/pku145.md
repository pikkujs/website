# PKU145: Missing Model

## Error Message

```
[PKU145] AI agent 'supportAgent' is missing the 'model' property.
```

## What Went Wrong

Every AI agent must declare which model it runs on. The Pikku CLI validates this at build time so a missing model surfaces immediately, rather than as a runtime failure the first time someone talks to the agent. Your `pikkuAgent` definition has no `model` property (or it's set to an empty value).

## How to Fix

Add a provider-qualified `model` to the agent definition:

```typescript title="support.agent.ts"
// ❌ Wrong — no model declared
export const supportAgent = pikkuAgent({
  name: 'supportAgent',
  instructions: 'Help customers with their orders.',
})
```

```typescript title="support.agent.ts"
// ✅ Correct
export const supportAgent = pikkuAgent({
  name: 'supportAgent',
  model: 'anthropic/claude-sonnet-5',
  instructions: 'Help customers with their orders.',
})
```

The model string must be in `<provider>/<model>` form — see [PKU146](./pku146.md) if you have a model but it isn't provider-qualified.

## AI Agent Best Practices

- Always qualify the provider (`anthropic/…`, `openai/…`) so the runtime knows which API to call.
- Pick the model per agent, not globally — a triage agent and a reasoning agent rarely want the same one.
- Keep the model string a literal so the inspector (and the Console) can display it.

## Common Mistakes

```typescript title="wrong.ts"
// ❌ Wrong — model pulled from env at definition time; the inspector can't see it
export const supportAgent = pikkuAgent({
  name: 'supportAgent',
  model: process.env.AGENT_MODEL,
})
```

```typescript title="correct.ts"
// ✅ Correct — literal, statically inspectable
export const supportAgent = pikkuAgent({
  name: 'supportAgent',
  model: 'anthropic/claude-sonnet-5',
})
```
