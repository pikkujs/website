# PKU410: Services Not Destructured

## Error Message

```
[PKU410] Function 'createTodo' does not destructure its services parameter, preventing tree-shaking optimization.
```

## What Went Wrong

This is a **warning-level lint**, not a build blocker (it only fails the build if you run the CLI with `--fail-on-warn`). Your function, middleware, or permission takes its first parameter — the services object — without destructuring it:

```typescript
export const createTodo = pikkuFunc<CreateTodo, Todo>(async (services, data) => {
  return services.database.insert('todos', data)
})
```

When you destructure (`{ database }`), the inspector can see exactly which services the function uses and tree-shake everything else out of the bundle for deployments that only include this function. An opaque `services` parameter forces Pikku to assume the function might touch *every* service, so nothing can be dropped.

## How to Fix

Destructure only the services you use:

```typescript title="todos.functions.ts"
// ❌ Warns — Pikku must bundle every service
export const createTodo = pikkuFunc<CreateTodo, Todo>(async (services, data) => {
  return services.database.insert('todos', data)
})
```

```typescript title="todos.functions.ts"
// ✅ Correct — only 'database' is bundled for this function
export const createTodo = pikkuFunc<CreateTodo, Todo>(async ({ database }, data) => {
  return database.insert('todos', data)
})
```

The same applies to middleware and permissions — they're checked too.

## Tree-Shaking Best Practices

- Destructure services in the parameter list, not in the body (`const { database } = services` inside the body is still opaque to the inspector).
- Don't pass the whole services object to helpers; pass the individual services a helper needs.
- If a function genuinely needs many services, list them all — the lint is about visibility, not count.

## Common Mistakes

```typescript title="wrong.ts"
// ❌ Still warns — destructured too late
export const createTodo = pikkuFunc<CreateTodo, Todo>(async (services, data) => {
  const { database } = services
  return database.insert('todos', data)
})
```

```typescript title="correct.ts"
// ✅ Correct — destructured in the signature
export const createTodo = pikkuFunc<CreateTodo, Todo>(async ({ database }, data) => {
  return database.insert('todos', data)
})
```
