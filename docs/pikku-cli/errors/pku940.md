# PKU940: RPC Invocation Type Cast

## Error Message

```
[PKU940] rpc.invoke() result is type-cast — remove the 'as' expression and rely on Pikku's generated types
```

Or, when the cast is on an argument:

```
[PKU940] rpc.invoke() has a type cast on an argument — remove the 'as' expression and rely on Pikku's generated types
```

## What Went Wrong

An `rpc.invoke()` call in your code uses an `as` cast — either on the result or on one of the arguments. Pikku generates precise input/output types for every RPC from the target function's contract; a cast overrides that machinery and tells the compiler to trust you instead. That silently disables the one guarantee RPC typing gives you: when the target function's contract changes, the compiler flags every caller. With a cast in place, the call keeps compiling and fails at runtime.

Generated files (`*.gen.ts`) are exempt — they may contain intentional casts.

## How to Fix

Delete the cast and let the generated types flow:

```typescript title="orders.functions.ts"
// ❌ Wrong — result cast, causes PKU940
const receipt = (await rpc.invoke('createReceipt', order)) as Receipt

// ❌ Wrong — argument cast, causes PKU940
await rpc.invoke('createReceipt', order as CreateReceiptInput)
```

```typescript title="orders.functions.ts"
// ✅ Correct — types come from the generated RPC map
const receipt = await rpc.invoke('createReceipt', order)
```

If the cast was papering over a real mismatch, fix the data instead:

- **Result type "wrong"?** Re-run `pikku all` — the generated types are stale, not wrong.
- **Argument doesn't fit?** Map it explicitly to the input shape (`{ orderId: order.id, ... }`) so the compiler checks the mapping.
- **Narrowing a union?** Use a type guard or schema parse, which is checked, rather than `as`, which isn't.

## RPC Best Practices

- Treat a needed cast as a smell that generated types are stale or the caller's data model has drifted.
- Regenerate (`pikku all`) after changing any function contract before fixing "type errors" by hand.
- Keep RPC names as string literals so the invocation is statically resolvable and fully typed.
