# PKU345: Extension Manifest Is Not Static

## Error Message

```
[PKU345] defineExtension: '[field]' must be a literal.
```

## What Went Wrong

`pikku all` reads `defineExtension` without running your code, so every field it records — a screen's `path`, `title`, `nav`, `scopes` and `app`, and the extension's `title` and `icon` — has to be written out as a literal. A variable, a template with substitutions or a function call can't be read.

## How to Fix

Write the value inline. A screen's `component` is the one field that stays a function, because it is loaded lazily:

```typescript
import { defineExtension } from '@pikku/core/addon'

export default defineExtension({
  title: 'Invoices',
  screens: [
    {
      path: '/',
      title: 'Invoices',
      nav: true,
      scopes: ['invoices:read'],
      component: () => import('./screens/Home.js'),
    },
  ],
})
```
