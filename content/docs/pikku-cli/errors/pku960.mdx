# PKU960: Knowledge Note Missing

## Error Message

```
[PKU960] N thing(s) in the code that no note describes
```

## What Went Wrong

`pikku knowledge validate` found functions or other things in your code that no knowledge-base note describes. This is a warning: it is reported once, as a count, and the full list of orphans is printed by the command's output.

`--fail-on-warn` is what turns it into a failure.

## How to Fix

Write a note for each thing listed, or remove the code it describes. Then run `pikku knowledge validate` again.
