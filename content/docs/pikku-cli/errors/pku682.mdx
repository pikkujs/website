# PKU682: Scenario Has No Feature

## Error Message

```
[PKU682] Scenario 'strayScenario' is listed by no pikkuFeature, so nothing downstream can reach it — a run stamps no feature onto its results, and a guide cannot cite it. Add it to a feature's `scenarios` array.
```

When some scenarios are built with a spread or a call, Pikku can't tell whether they're listed, and it downgrades to a **warning** instead:

```
[PKU682] 'a', 'b' appear in no feature's `scenarios` array, but 'featureX' builds theirs with a spread or a call, so one of them may still be listed there. List those scenarios literally and this becomes a definite answer either way.
```

## What Went Wrong

Every scenario belongs to a feature. `pikkuFeature({ name, scenarios: [...] })` groups scenarios the way Gherkin's `Feature:` groups `Scenario:`, and the feature is what a run reports against. A scenario that no feature lists is orphaned:

- a run can't stamp a feature onto its results
- `--features` can't select it
- a guide can't cite it

The inspector checks this once it has seen every scenario and every feature, and flags each scenario that appears in no feature's `scenarios` array.

## How to Fix

Add the scenario to a feature's `scenarios` array:


```typescript @snippet scenarioFeature
```

If you build a feature's `scenarios` with a spread or a function call, the inspector can't read it statically and only warns. List the scenarios literally to get a definite answer either way.
