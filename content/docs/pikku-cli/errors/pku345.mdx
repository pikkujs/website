# PKU345: Addon Screens Are Not Static

## Error Message

```
[PKU345] defineScreens: '[field]' must be a literal.
```

## What Went Wrong

`pikku all` reads `defineScreens` without running your code, so every field it records — a screen's `path`, `title`, `nav`, `scopes` and `app`, and the addon's `title` and `icon` — has to be written out as a literal. A variable, a template with substitutions or a function call can't be read.

## How to Fix

Write the value inline. A screen's `component` is the one field that stays a function, because it is loaded lazily:

```typescript @snippet ea-define-screens
```
