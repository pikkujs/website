# PKU146: Invalid Model

## Error Message

```
[PKU146] AI agent 'supportAgent' uses model 'gpt-4', which must be provider-qualified as '<provider>/<model>' (e.g. 'openai/gpt-4').
```

## What Went Wrong

Your AI agent declares a `model`, but the string has no provider prefix. Pikku routes agent calls through the provider named before the `/` — with a bare model name like `'gpt-4'` it can't tell whether you mean OpenAI, Anthropic, a local runner, or a proxy, so the build fails rather than guessing.

## How to Fix

Prefix the model with its provider, so a bare `'gpt-4o-mini'` becomes `'openai/gpt-4o-mini'`:

```typescript @snippet ea-agent-model
```

## AI Agent Best Practices

- Use the `<provider>/<model>` form everywhere a model is named, including per-call overrides.
- Copy exact model IDs from the provider's docs — typos in the model half fail at runtime, not build time.
- When switching providers, change only the prefix and re-run your scenarios to compare behaviour.

## Common Mistakes

A colon looks qualified but isn't: `'openai:gpt-4o-mini'` still fails. A forward slash separates provider and model, as in `'openai/gpt-4o-mini'`.
