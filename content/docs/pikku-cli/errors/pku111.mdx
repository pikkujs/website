# PKU111: Missing Name Property

## Error Message

```
[PKU111] MCP prompt is missing the required 'name' property.
```

## What Went Wrong

You're wiring an MCP prompt without a `name`. The name is how a client asks for the prompt, so it can't be inferred.

MCP tools never hit this — they have no wiring call at all. `pikkuMCPToolFunc` takes the tool name from the export name, or from an explicit `name` option.

## How to Fix

Add a `name` property to your prompt wiring:

```typescript @snippet mcpPrompt
```

## Common Mistakes

- Forgetting to add the `name` field entirely
- Using `title` instead of `name` (resources use `uri` and `title`)
- Leaving the `name` field as an empty string
