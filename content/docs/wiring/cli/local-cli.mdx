# Local CLI

Local CLI commands execute directly in your local Node.js process. No network requests, instant execution.

## Configuration

Add a local CLI entrypoint to `pikku.config.json`:

```json
{
  "cli": {
    "entrypoints": {
      "my-cli": [
        {
          "type": "local",
          "path": ".pikku/cli-local.gen.ts"
        }
      ]
    }
  }
}
```

Run `npx pikku` to generate the CLI executable at the path set on the entrypoint (`.pikku/cli-local.gen.ts` above). The generated file is TypeScript, so run it with a TS runner such as `tsx`.

## Usage

```bash
npx tsx .pikku/cli-local.gen.ts greet Alice
npx tsx .pikku/cli-local.gen.ts user create alice@example.com
```

Or add to `package.json`:

```json
{
  "scripts": {
    "cli": "tsx .pikku/cli-local.gen.ts"
  }
}
```

Then run:

```bash
yarn cli greet Alice
yarn cli user create alice@example.com
```

That's it. Local CLI runs your functions locally.
